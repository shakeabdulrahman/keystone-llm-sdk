# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the
code. Harassment or discrimination of any kind isn't tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/shakeabdulrahman). Reports are handled confidentially.
